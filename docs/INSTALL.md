# How to install DIVIORA Music (no technical steps)

All installers are on one page: **https://github.com/MS2022Singh/Diviora/releases/latest**
(GitHub rebuilds them automatically every time the project is updated.)

> If the repository is **private**, you must be signed in to GitHub to see that page. To share the app
> with other people, make the repository public, or send them the file directly.

## Android phone or tablet
1. On the phone, open the link above in Chrome.
2. Tap **DIVIORA-Music-Android.apk** to download it.
3. When the download finishes, tap **Open**. If the phone asks, tap **Settings → Allow from this source**, then go back.
4. Tap **Install**, then **Open**.
5. Allow **Music and audio**, **Videos** and **Notifications** when asked. For routines on the exact minute:
   **Settings (inside DIVIORA) → Exact alarms → Open → turn on**.

Updating: download the new APK the same way and tap **Install**. Your library and routines are kept.

## Windows 10 / 11
1. Open the link above and click **DIVIORA-Music-Windows.msi**.
2. Double-click the downloaded file. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**
   (this appears because the app is not code-signed yet).
3. Click **Next → Install → Finish**. Start it from the Start menu: **DIVIORA Music**.

## macOS
1. Open the link above and click **DIVIORA-Music-macOS.dmg**.
2. Open the file and drag **DIVIORA Music** into **Applications**.
3. The first time only: **right-click the app → Open → Open** (the app is not notarised by Apple yet).

## Linux (Ubuntu, Debian, Mint)
1. Download **DIVIORA-Music-Linux.deb** and double-click it (it opens Software Install), or run:
   ```bash
   sudo apt install ./DIVIORA-Music-Linux.deb
   ```
2. Start **DIVIORA Music** from the app menu.

## Using it in 3 steps
1. **Add music:** phone: it finds your music automatically (or **Library → +** for files, folders and links).
   Computer: **Library → Files / Folder / Link**.
2. **Play:** tap or click any song or video.
3. **Schedule:** press the **⏰ alarm icon** next to any song (or **Routines → New routine**), then choose **your own
   date and time** (once, every day, weekdays, chosen days or monthly). Add as many times as you like and press **Save**.
   On a computer, keep DIVIORA running (closing the window keeps it in the system tray) so routines can play.
